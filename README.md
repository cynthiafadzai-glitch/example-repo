# Shoe Inventory Management System

## Project Description

This is a Python-based shoe inventory management program developed as part of my programming coursework.

The program uses object-oriented programming (OOP) principles to organise and manage shoe inventory records.

## Features

- Stores shoe information such as country, product code, product name, cost and quantity.
- Reads inventory information from a text file.
- Uses Python classes and functions to manage inventory data.
- Includes error handling for missing files and invalid data.

## Technologies Used

- **Python**
- **Object-Oriented Programming (OOP)**
- **File Handling**

## Project Files

- `inventory.py` — Main Python program.
- `inventory.txt` — Shoe inventory data.
- `README.md` — Project documentation.

## How to Run

1. Ensure Python is installed on your computer.
2. Keep `inventory.py` and `inventory.txt` in the same folder.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python inventory.py
```
